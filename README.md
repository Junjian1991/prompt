# AI 图像生成提示词编辑器

一款专业级的 AI 图像生成提示词编辑器，提供细粒度的提示词编写、编辑、收藏、分享功能。

## ✨ 特性

- 🎨 **100+ 细化选项**：覆盖人物、场景、道具、风格等全方位参数
- ✏️ **手写输入**：支持手写输入，自动识别转换为文本
- 💾 **自定义保存**：每个模块都支持自定义输入并保存
- 🔍 **智能搜索**：快速查找和浏览海量提示词
- 👥 **用户系统**：注册、登录、个人中心
- 💖 **收藏分享**：收藏、评分、评论提示词

## 🚀 快速开始

### 方法一：直接打开

直接在浏览器中打开 `index.html` 文件即可使用。

### 方法二：本地服务器

```bash
# 使用 Python
cd PromptEditor
python -m http.server 8080

# 或使用 Node.js
npx serve .

# 然后访问 http://localhost:8080
```

## 🎯 主要功能

### 1. 提示词编辑器

支持以下模块的细粒度编辑：

- **主体类型**：人物、场景、道具、动物、混合体
- **人物参数**：种族、性别、年龄、发型、发色等
- **服装配饰**：服装类型、材质、状态、配饰
- **场景环境**：场景类型、光照、天气
- **视角构图**：镜头类型、角度、构图方式
- **道具细节**：道具类型、材质、状态
- **艺术风格**：插画风格、图片比例
- **输出格式**：分辨率、格式
- **参考图**：上传参考图、控制参考强度
- **文化设定**：文化背景、年代设定
- **合规设置**：年龄分级、暴力程度

### 2. 自定义输入与手写功能

每个模块底部都设有"自定义"输入区域：

- 支持输入任意文本描述
- 支持手写输入（Ctrl+H 快捷键）
- 手写文字自动识别为文本
- 所有内容自动保存到本地存储
- 支持保存到个人词库

### 3. 用户系统

- 邮箱注册和登录
- 个人中心管理
- 我的提示词
- 我的收藏
- 我的词库
- 手写记录
- 账户设置

### 4. 提示词库

- 浏览所有公开提示词
- 关键词搜索
- 分类筛选
- 排序（最新、最热、评分最高）
- 查看详情、收藏、点赞

## 📖 使用指南

### 创建提示词

1. 点击导航栏的"编辑器"
2. 在左侧选择模块（人物参数、服装等）
3. 在中间区域选择或输入选项
4. 在底部自定义输入区添加额外描述
5. 点击"保存发布"完成创建

### 手写输入

1. 在编辑器中点击"✍️"按钮或按 `Ctrl+H`
2. 在手写板上绘制内容
3. 选择画笔颜色和粗细
4. 点击"识别文字"进行识别
5. 确认后自动插入到自定义输入区

### 保存到词库

1. 在自定义输入区输入内容
2. 点击"保存到词库"
3. 之后可以在"个人中心 > 我的词库"中查看和使用

## 🔧 数据存储

所有数据都保存在浏览器本地存储中：

- `prompt_editor_users`：用户数据
- `prompt_editor_prompts`：提示词数据
- `prompt_editor_drafts`：草稿数据
- `prompt_editor_word_bank`：个人词库
- `prompt_editor_handwriting`：手写记录

## 📝 注意事项

- 请勿在多个浏览器标签页中同时使用，以避免数据冲突
- 重要数据建议定期导出备份
- 清除浏览器数据会导致所有本地存储的数据丢失
